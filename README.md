# Rogerio Ceni: O Maior Goleiro do Mundo

Este é um projeto web desenvolvido para homenagear e documentar a trajetória de Rogerio Ceni, o maior ídolo da história do São Paulo Futebol Clube e o maior goleiro-artilheiro do futebol mundial. O site apresenta argumentos históricos, estatísticas e vídeos que comprovam sua genialidade no esporte.

---

## Tecnologias Utilizadas

O projeto foi construído em um arquivo único utilizando as linguagens fundamentais da web:
*   **HTML5:** Estruturação semântica do conteúdo.
*   **CSS3:** Estilização visual, incluindo background fixo, efeitos de sombra (box-shadow) e Design Responsivo (Media Queries) para adaptação perfeita em dispositivos móveis.
*   **JavaScript (Vanilla):** Lógica de interação para os botões de curtir/descurtir, permitindo incremento e decremento dinâmico dos números.

---

## Estrutura do Site (Topicos)

O conteúdo da página está dividido de forma lógica para guiar o leitor:

1.  **Introdução:** Quem é Rogerio Ceni, seus principais títulos (30 na carreira) e sua posição como maior ídolo do SPFC.
2.  **O Auge no Mundial de 2005:** Destaque para a atuação lendária contra o Liverpool no Japão, onde foi campeão mundial e eleito o melhor jogador do torneio.
3.  **A Revolução na Posição de Goleiro:** Como ele mudou o esporte ao se tornar um construtor de jogadas e uma arma ofensiva letal, pavimentando o caminho para o "goleiro moderno".
4.  **A Conclusão Lógica:** Análise dos fatos, recorde do Guinness (131 gols) e sua lealdade de mais de 1.200 jogos pelo mesmo clube.
5.  **Provas (Vídeos):** Seção interativa com iframes do YouTube contendo lances históricos do M1TO.

---

## Funcionalidades e Recursos

*   **Design Responsivo:** No computador, a foto de perfil e o texto introdutório ficam lado a lado. No celular, eles se empilham de forma elegante e centralizada.
*   **Botões Interativos:** O usuário pode clicar nos botões de curtir logo abaixo da foto principal para contabilizar interações. Os botões mudam de cor ao serem ativados.
*   **Mídia Incorporada:** Reprodução de vídeos do YouTube diretamente na página.

## Arquivos Necessários para Rodar o Projeto

Para que o site funcione perfeitamente na sua máquina, os seguintes arquivos de imagem devem estar salvos na mesma pasta do código principal:

## Como visualizar

1. Faça o download ou clone este repositório.
2. Certifique-se de que as 3 imagens citadas acima estão na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` para abri-lo no seu navegador de preferência.
